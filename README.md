# DevVault

**Your code. Smarter.**

DevVault is an AI-powered developer tool by **StakLabs**, designed to help developers save, organise, reuse, and improve their code snippets in one place.

Instead of searching through old projects to find that one function you wrote weeks ago, DevVault keeps your useful code organised and puts AI tools right at your fingertips.

## ✨ Features

- **Code Snippets** — Save reusable code snippets with titles, descriptions, languages, and categories.
- **AI Rewrite** — Rewrite existing code with AI to improve its readability, structure, and quality.
- **Search** — Find snippets quickly using the built-in search.
- **Favourites** — Mark important snippets for quick access.
- **Language Filtering** — Organise and filter snippets by programming language.
- **Sorting** — Arrange snippets to find recently added or updated code.
- **Copy to Clipboard** — Copy snippets instantly for use in your projects.
- **Persistent Storage** — Keep your snippets saved locally between sessions.

## 🤖 Built for AI

AI is at the heart of the DevVault experience.

DevVault aims to make working with code more efficient by integrating AI directly into the tools developers already use.

Planned AI capabilities include:

- **AI Explain** — Understand unfamiliar code through clear explanations.
- **AI Debug** — Identify potential bugs and suggest fixes.
- **AI Generate** — Generate reusable snippets from natural-language descriptions.
- **AI Improve** — Improve code readability, maintainability, and performance.

These capabilities can be introduced progressively as the platform develops.

## 🚀 Getting Started

Go to https://staklabs.github.io/DevVault

**Note:** AI functionality requires the appropriate backend and API configuration. Keep API keys on the server rather than exposing them in client-side JavaScript.

## 🔒 Privacy

DevVault uses browser Local Storage to persist snippets locally. Data stored this way remains in the browser on that device unless additional synchronisation features are implemented.

If AI features send code to an external API, review the integration before submitting sensitive or proprietary code.
